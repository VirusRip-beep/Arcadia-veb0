ARCADIA BETA 0.1 — УСТАНОВКА НА ANDROID / PYDROID 3

ВАЖНО:
- Никогда не отправляй BOT_TOKEN в чат и не загружай его в GitHub.
- Сейчас это тестовый прототип. Не используй реальные деньги.
- Telegram Web App требует HTTPS. localhost работает только для локального предпросмотра.
- В этом архиве нет готовых картинок персонажей: карточки используют собственные текстовые/графические заглушки. Используй изображения, на которые у тебя есть права.

ЧТО ВНУТРИ:
server.py        — Telegram-бот + Flask API + SQLite
web/index.html   — интерфейс
web/style.css    — оформление
web/app.js       — логика интерфейса
requirements.txt — библиотеки

ШАГ 1. РАСПАКУЙ
Распакуй ZIP в отдельную папку на телефоне, например:
Internal storage/ARCADIA_BETA_0_1/

ШАГ 2. УСТАНОВИ БИБЛИОТЕКИ В PYDROID 3
Открой Pydroid 3 → Terminal и выполни:
pip install -r /storage/emulated/0/ARCADIA_BETA_0_1/requirements.txt

Если путь не подходит, перейди в папку проекта через файловый менеджер Pydroid и выполни:
pip install Flask==3.0.3 pyTelegramBotAPI==4.21.0

ШАГ 3. СОЗДАЙ БОТА
В Telegram открой @BotFather → /newbot.
Скопируй токен себе в безопасное место. НЕ присылай его никому.

ШАГ 4. НАСТРОЙ SERVER.PY
В Pydroid открой server.py.
В начале файла найди строку:
BOT_TOKEN = os.getenv("BOT_TOKEN", "").strip()

Для первого запуска проще заменить её на:
BOT_TOKEN = "ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER"

Токен хранится только у тебя. Не публикуй этот файл с токеном.

ШАГ 5. ЛОКАЛЬНЫЙ ПРЕДПРОСМОТР
Временно оставь WEBAPP_URL пустым.
Запусти server.py кнопкой ▶ в Pydroid.
Открой браузер на том же телефоне:
http://127.0.0.1:8080/?demo=1

Локальный демо-режим нужен только для проверки интерфейса. Он не является настоящей Telegram-авторизацией.

ШАГ 6. ЗАПУСК В TELEGRAM
Чтобы Telegram открыл Web App, ему нужен публичный HTTPS-адрес.
Нужно:
1) Настроить HTTPS-туннель на порт 8080 (например, Cloudflare Tunnel или другой доверенный туннель).
2) Получить HTTPS URL.
3) В server.py установить:
WEBAPP_URL = "https://ТВОЙ-АДРЕС/"
4) Перезапустить server.py.
5) Написать своему боту /start и нажать «Открыть ARCADIA».

Не используй случайные бесплатные прокси-ссылки и не вводи токен бота на сторонних сайтах.

КАК РАБОТАЕТ ЗАЩИТА:
- Для реального Telegram Web App сервер проверяет подпись initData.
- Обычный браузер без Telegram initData получает отказ.
- При остановке процесса Pydroid останавливаются и бот, и API.
- Если Telegram Bot API недоступен, бот помечается как отключённый, игровые API не работают.
- Локальный demo-режим включён только для loopback адреса и предназначен исключительно для предпросмотра.

ГДЕ ХРАНЯТСЯ ДАННЫЕ:
Файл arcadia.sqlite3 создаётся автоматически рядом с server.py.
Сделай резервную копию этого файла перед обновлениями.
